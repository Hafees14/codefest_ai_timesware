# Skills

This folder is for any custom AI skills, prompt templates, or reusable
instruction sets your team developed or used during this project (for
example, a custom prompt template used repeatedly for a specific
extraction or review task).

If your team did not create or use any custom skills beyond ad-hoc chat
prompting, note that explicitly here rather than leaving this folder
looking accidentally empty:

No custom skills were developed for this project. All AI assistance was
via direct conversational prompting with Claude, as documented in
`../claude.md` and `../ai-usage-disclosure.md`.
